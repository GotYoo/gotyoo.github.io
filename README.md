# GotYoo · Personal Site & Interface

> 个人主页与作品展示 · [https://lxmhappy.live](https://lxmhappy.live)

## 页面架构

- **首页 (`/`)**：基于 Air.inc 官方设计形态与审美规范重构的主页，包含自然云天全景、轻量玻璃态视窗卡片与三模块（Projects、Writing、Pedigree）互动交互。
- **项目 (`/projects/`)**：工程项目、开源实践与设计作品归档。
- **文章 (`/blog/`)**：技术笔记、工程反思与公开思考。
- **生活 (`/life/`)**：日常摄影与生活切片。
- **简历 (`/resume/`)**：个人背景与工作履历。

## 技术栈

- 静态构建：Jekyll · GitHub Pages
- 样式系统：原生 CSS（现代排版、流式栅格、高质感质地与微动效）
- 交互能力：原生 Vanilla JavaScript，无冗余重型依赖库
