# Kairo · Learner & Builder Workbench

> Kairo (吴汉卿) 的个人主页与工程工作台 · [https://lxmhappy.live](https://lxmhappy.live)

## 核心定位与设计哲学

- **定位**：AI Agent 决策系统、本地 Harness 与系统工程开发者的个人工作台。
- **美学规范**：现代极客暗黑/明亮双色自适应工作台，融合高精度微网格、毛玻璃浮岛导航、MiniCodeAgent 交互式执行仿真终端与触觉式一键联络。
- **原则**：真实优先（Authenticity）、架构清晰（Structure First）、持续演进（Iterative Growth）。

## 页面架构

- **首页 (`/`)**：Learner & Builder 工作台，包含 AI Agent 终端执行仿真、精选工程项目、深度公开手记、摄影切片、学术履历与一键邮箱复制。
- **项目 (`/projects/`)**：MiniCodeAgent、ZhiStack 智栈开发者社区、NegAuto 彩负自动去色罩、TravelPlanning 多智能体、CommandBox 与系统工程归档。
- **文章 (`/blog/`)**：技术笔记、系统手记与长周期思考。
- **生活 (`/life/`)**：摄影切片与阶段性印记时间线。
- **简历 (`/resume/`)**：学术背景与在线 PDF 简历浏览/下载。
- **关于 (`/about/`)**：个人背景介绍、工程准则与学术研究方向。

## 技术特性

- **静态引擎**：Jekyll · GitHub Pages 自动化流水线
- **样式系统**：自研 Design Tokens 规范，CSS Custom Properties 驱动暗黑/明亮双主题无缝切换
- **交互引擎**：原生高性能 Vanilla JavaScript（零第三方重型依赖，秒开无延迟）
- **快捷交互**：支持全局 `Cmd+K` / `Ctrl+K` 快速指令搜索、ESC 关闭与键盘焦点导航
