Personal Interface Architecture

Role: Design & Systems Engineering • Stack: CSS Tokens · Jekyll · Vanilla JS • Deployment: GitHub Pages

01 / 背景与问题 · Context

问题不是页面不够炫酷，而是过去的内容容易堆砌在同一层级。招聘方难以快速定位工程能力与证据，个人生活切片也容易挤占专业判断的注意力。

02 / 架构决策 · Decisions

将整个个人网站明确解耦为五个长期维护的独立界面：

  • Home：Learner & Builder 个人主页与工程工作台，承担定位、精选项目与控制台交互。
  • Projects：工程项目归档与深度案例分析。
  • Blog：沉淀长周期思考的技术笔记与复盘文章。
  • Life：独立、真实且低调的照片、旅行与生活痕迹。
  • Resume：直接展示可在线阅读与下载的高清 PDF 简历。

03 / 交互与性能原则 · Performance & Motion

动态交互负责解释层级，不负责代替内容本身。全站放弃重型框架与庞大 CSS 库，采用纯原生 CSS 与轻量 Vanilla JS，保证首屏在任何设备上 0 延迟秒开，并支持优雅的深浅主题切换、快捷指令（⌘K）与减弱动态偏好。

04 / 验证与上线 · Validation

每次重构均经过桌面与移动端渲染测试、无障碍访问测试、静态编译语法校验与 GitHub Pages 自动化流水线验证，确保对外公开链接 100% 可用且无控制台报错。

从真实需求出发，做好每一次工程选型与审美表达。

欢迎就本站的前端架构与工程设计展开交流。
